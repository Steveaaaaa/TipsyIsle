# 微醺屿 · TipsyIsle

**让每一条舍不得删的剧情，都有地方继续。**

一张卡聊到几百楼，最舍不得丢的，往往是一件小事：某个人终于改了对你的称呼，或者第二十七楼那把一直没用上的钥匙。偶尔你也会想起，故事里还有一扇门，当时没有推开。

微醺屿是一款为 **AI RP（AI 角色扮演）** 打造的本地客户端，可在 Windows、Android 和本地网页上使用。我们想把它做成 AI RP 社区愿意长住的港湾：玩家能把故事写下去，把界面改成自己喜欢的样子；创作者能带着已有的作品来，也能在这里做出新的玩法。

[开一局](#开一局) · [酒馆作品兼容](#带着熟悉的卡来) · [给社区创作者](#给写卡做预设写插件的人)

## 同一扇门，可以推开两次

在开场后的模型回复旁，点「从这里重新选择」。昨晚写过的那条路会留下，你可以从同一段剧情做出另一个决定。等两条路都走远了，再打开故事路线图看摘要：可以只看眼前这个分叉，也可以总览整张角色卡的会话和路线。选一条继续时，正文、剧情变量和世界书的计时状态会回到对应的进度。在哪条路上拿到的钥匙，就留在哪条路上。

## 合上电脑，手机接着写

两端在同一局域网配对后，可以同步角色卡、世界书、预设、个人资料和剧情进度。游玩时先保存到本机，空下来再同步；准备换设备时，也可以点「立即同步」。就算两端离线时各自续写了同一个存档，重新连上也会保留各自的进度。同一本世界书被两端分别改过，也可以看过差异再选。同步不用搭云端服务，模型地址和密钥在每台设备上各自设置。

## 住久了，就按自己的习惯布置

换壁纸、换字体，给标题和输入框各设一套字号。还可以改掉软件名字、替换按钮图标，把常用操作移到顺手的位置，给手机留一套单独的布局。改动可以先预览，再保存或退回上一版；喜欢的搭配也能打成外观包分享。

会写 CSS 的作者，可以用 `data-ti-shell` 和 `data-ti-part` 定位软件的界面和部件。外观样式有自己的作用范围，角色卡作者写的消息气泡、状态栏和互动页面仍由原来的渲染环境处理。

## 带着熟悉的卡来

SillyTavern 和它的社区积累了多年的角色卡、预设、世界书和作者工具。那是创作者花了时间做出来的作品，也是很多玩家熟悉的玩法。微醺屿支持导入酒馆格式的 PNG／JSON 角色卡、JSON 世界书和预设；卡里自带的世界书会随角色启用。现有的兼容层也接入了宏、正则、提示词模板、MVU 变量与作者 HTML 互动页面等能力。

兼容范围取决于作品实际用到的接口。依赖特定酒馆助手行为、第三方扩展或原版界面结构的卡与插件，可能还需要适配。遇到问题，欢迎带上作品依赖、发生在哪一步，以及能分享的复现素材；这些真实的用法会告诉我们下一步该补什么。

## 给写卡、做预设、写插件的人

我们希望社区既能继续做熟悉的作品，也能做出以前难以实现的玩法。微醺屿有一套独立的原生插件 API：用 [TypeScript 类型](packages/plugin-sdk/index.d.ts) 查接口，用 [Manifest Schema](packages/plugin-sdk/manifest.schema.json) 声明版本、入口和权限，再把作品签名打包成 `.tipsy-plugin`。插件逻辑在 Web Worker 内的 QuickJS 环境中执行，经由宿主 API 访问获准的能力。玩家可以在「设置 → 插件」查看授权和本次运行的日志。

| 想做什么 | 可以从哪里接入 |
| --- | --- |
| 做路线笔记、复盘或搜长剧情 | 分页读取会话和路线树，按版本读取消息与变量；用 `device`、`route`、`reply` 作用域分别保存本机、路线与单条回复的数据。 |
| 改善模型看到的上下文 | 在世界书扫描前后通过 `beforeScan`／`afterScan` 参与提示词组装，提供宏和注入内容、整理送给模型的历史，或声明模型可调用的只读工具。 |
| 做有界面的功能，或和别的插件配合 | 在输入栏、消息或应用菜单注册命令，打开弹窗、侧栏或全屏界面；通过获准的连接发起对话、生图、语音或嵌入任务，也可以声明带版本的插件服务。 |
| 写会修改剧情或资源的功能 | 走 `preview → commit → undo` 接口，提交时核对修改所依据的版本，避免把另一条路线或后续修改悄悄覆盖。 |

[插件 SDK](packages/plugin-sdk) 内含类型、清单 Schema 与打包 CLI。`host.capabilities()` 可查询当前宿主的 API 版本和可用能力；安装依赖后，可在仓库根目录运行 `npm run plugin:pack -- --help` 查看打包用法。

欢迎来提 [Issue](https://github.com/Steveaaaaa/TipsyIsle/issues)。一张讲不下去的卡，一个创作时找不到的接口，或一种现在还玩不到的剧情，都可以从具体例子谈起。我们想知道的，是你想写什么，以及你在哪一步不得不停下来。

## 开一局

安装 [Node.js](https://nodejs.org/) 22.19.0 或更新版本，在项目目录运行：

```sh
npm ci
npm start
```

打开 [http://localhost:5179](http://localhost:5179)。在馆藏导入一张角色卡，然后到「设置 → 模型连接」填入自己的服务地址、密钥和模型，保存后选一个开场。第一次来，也可以跟着应用内的引导走一遍。

<details>
<summary>只构建网页，或自己打包 Windows／Android 版</summary>

- 网页资源：`npm run build`。`npm start` 会同时启动网页、本地模型网关与兼容服务。
- Windows 安装包：配置 [Tauri 开发环境](https://v2.tauri.app/start/prerequisites/)后，运行 `npm run windows:build`。
- Android 安装包：仓库内的发布脚本面向在 Windows 上构建 ARM64 APK。准备 Android SDK 37、NDK 28.2.13676358 与本机的 `src-tauri/gen/android/keystore.properties` 后，运行 `npm run android:build`。签名文件由打包者自行配置。

</details>
