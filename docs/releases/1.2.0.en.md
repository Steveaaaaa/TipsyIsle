## TipsyIsle 1.2.0

> Since v1.1.6, this release marks a major milestone with **Plugin SDK 1.2**, the flagship **Lumina Director** visual narrative plugin, native **OpenAI Responses** support, **in-flow Shadow DOM compatibility films**, **SPreset runtime**, and fixes for Gemini streaming, Izumi/MVU compatibility, and mobile stability.

### Flagship Plugin & Plugin SDK 1.2

- **Lumina Director (v1.2.16):** Built on Plugin SDK 1.2.0 (`releases/plugins/lumina-director.tipsy-plugin`), bringing an automatic visual director to your stories:
  - **Zero-config visual bible:** Reads character cards, worldbook character entries, personas, and galleries to bind reference images automatically, with first-frame casting bootstrap for multi-character or simulator cards.
  - **Streaming head-start & full-reply fallback:** Triggers background rendering early via `story.replyCheckpoint` on clear transitions or strong visual beats, or waits for `story.replySaved` on quieter openings, including observational slice-of-life shot detection.
  - **Multi-provider image generation & layout adaptation:** Supports OpenAI-compatible, Gemini native multimodal, NovelAI V4.5 (coordinate anti-bleed & reference images), ComfyUI auto-slot workflows, and SD WebUI, adapting aspect ratio and style to your reading layout.
  - **In-place Take Stack & scrolling stage:** Flip takes in place (`< 1/2 >`), reroll a shot (`↻`), collapse into an amber film badge, inspect full saved prompts in the Darkroom, keep branch-aware continuity, and power illustrated chronicles via the `chronicle` plugin service.
- **Plugin SDK 1.2.0 (`@tipsy-isle/plugin-sdk`):** Adds `ui.stage`, `ui.surface`, `ui.export`, `ReplyMediaSlot`, `story.replyCheckpoint`, image adapter & job scheduling, visual/vector indexing, and `director.d.ts`.

### Model Protocols & Streaming

- **Native OpenAI Responses adapter:** Adds native OpenAI Responses API support with immediate saved model channel takeover.
- **Gemini streaming & thought phases:** Fixes Gemini native streaming/thought phases and incremental JSON/NDJSON/SSE framing.
- **SPreset & message metrics:** Adds SPreset runtime/output stream support and a message metrics bar.

### Compatibility & Story Runtime

- **In-flow Shadow DOM compat films:** Renders compatible interactive card blocks inside isolated in-flow Shadow DOM surfaces with adaptive media geometry and block reconciliation.
- **Izumi / MVU & script fixes:** Allows non-structural in-place edits during generation prep, syncs `WORLD_INFO_ACTIVATED` edits into prompt assembly, guards MVU JSONPatch parsing against non-array and empty blocks, and fixes global script deletion persistence and HTML beautification compatibility.

### UI, Editing & Stability

- **Message editing & mobile polish:** Adds a dedicated message edit dialog, inline mobile appearance workbench tab, plugin model back navigation, and a flattened settings UI.
- **Cleanup & reliability:** Removes legacy CSS and dead code, and improves sync deduplication and in-app update handling.
