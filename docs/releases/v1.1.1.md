# 每条故事，都有自己的记忆

- **柏宝书跟着剧情分支走。** 兼容原版柏宝书 1.3.5。分叉后，在 A 线补写或删除旧楼摘要，不会改动 B 线的记忆。切换前会先保存已经完成的改动；向量召回和本地索引也按路线分开。「带记忆开新聊天」可以带走当前路线的一份快照。
- **夜灯畅谈有了独立的会话列表。** 打开就能新建对话或找回之前聊过的内容，不用再去剧情历史里找，也不挤占角色馆藏。
- **Windows 和 Android 可直连 Google Gemini。** 使用 AI Studio 的接口地址和密钥，就能获取模型列表并开始聊天。第三方中转请按服务商说明选择接口协议。
- **酒馆扩展安装及接口兼容改进。** 从 GitHub 安装扩展时，浅克隆失败可改用官方 ZIP；兼容层也补齐了柏宝书所需的部分聊天、世界书与向量接口。

柏宝书向量索引保存在本机。换设备时会带上存档内的摘要；向量索引和冻结的向量包不会随存档迁移。
