# 欢迎客官登岛一览风光

TipsyIsle `1.1.0`

初次登岛，可以带一张熟悉的角色卡，也可以带上那段写了很久、还没写完的故事。要是已经来过，下次打开，会回到你上次离开时的页面。

- **旧故事可以接着写。** 支持导入酒馆的 `.jsonl` 聊天记录。TipsyIsle 的故事也能导出为 `.tipsy-story`，把同一会话的多条路线、剧情状态和随包资源带到另一台设备。
- **喜欢的外观可以都留下。** 外观包导入后会保存在库里，可以随时切换、管理，不用再找原文件。
- **想随便聊聊，就开一盏夜灯。** 「夜灯畅谈」可以直接和模型聊天，不用先选角色卡或叙事预设。
- **在手机上玩卡更顺手。** 改进了卡内悬浮组件的触控拖动、双指缩放和全屏支持，也改善了回看早期楼层时的渲染。
- **看完更新日志，再决定要不要装。** 发现新版时，可以查看更新说明，选择安装、稍后再看，或忽略这一个版本。设置里也能随时回看当前版本的日志。

新手引导也更新了。想从酒馆搬来一段故事，可以先看[迁移说明](https://github.com/Steveaaaaa/TipsyIsle/blob/main/docs/MIGRATING_FROM_SILLYTAVERN.zh-CN.md)。
