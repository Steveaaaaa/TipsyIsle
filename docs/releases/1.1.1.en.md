## What's new in TipsyIsle 1.1.1

- **Each story route keeps its own memories.** The compatibility layer supports the original ST-BaiBai-Book 1.3.5. Routes inherit saved memories at the fork; later edits to a shared message's summary stay on the current route. Finished edits are saved before switching, vector recall is scoped to the route, and starting a new chat with memories takes a snapshot of the current route.
- **Find past Lamplight Chats at a glance.** Start a new conversation or reopen an old one from its own list, separate from your character library and story history.
- **Connect directly to Google Gemini.** The Windows and Android apps can list models and chat through the Gemini API (AI Studio). If you use a proxy, choose the protocol specified by your provider.
- **Improved SillyTavern extension support.** GitHub installs can fall back to the official ZIP archive when a shallow clone fails. The adapter also covers more of the chat, worldbook, and vector APIs used by ST-BaiBai-Book.

Vector indexes and frozen vector bundles are stored on the device. Saved summaries travel with the story; those indexes and bundles stay local.
