## 故事继续，遇到问题也有迹可循

- **报错时，可以直接导出日志。** 点错误通知里的「导出错误日志」，确认后将运行环境、已安装的插件和脚本、近期故障保存为 `.txt`。也可到「设置 → 高级与诊断 → 错误日志」查看和清空记录。文件由你决定是否分享；日志不包含 API 密钥、聊天正文和完整请求。
- **更新检查能说明卡在哪一步。** 日志会区分连接超时、GitHub 返回错误、已经是最新版本、用户已忽略，以及发现新版但缺少适用的安装包。
- **支持使用 HTTP 地址获取模型列表。** 安装版调整了网络访问范围，只有 HTTP、使用自定义端口的模型服务也能接入。服务本身仍须提供所选协议的模型列表接口。
- **补齐角色卡和预设所用的酒馆弹窗接口。** 兼容环境支持更多弹窗行为，包括输入、确认和图片裁剪；弹窗也能在作者页面初始化期间显示。
- **正文里的台词更容易认出来。** 普通阅读正文会突出 `“…”`、`"…"` 和 `「…」` 中的台词，作者自带样式的互动页面保留自己的配色。
