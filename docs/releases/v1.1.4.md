## 1.1.4：删楼修复、多模型连接与酒馆兼容

### 修复

- **删除楼层能正常保存。** 修复删除单条消息时阅读区变成纯色、重开后消息又出现的问题。删除后会重新编号并保留后续消息；写入存档失败时会回退。角色会话仍会重新初始化兼容运行环境，让脚本按新的楼层编号运行。
- **卡片脚本和模板报错更准确。** 修复部分卡片使用 `window.parent` / `top` 时的跨域报错，以及带 Markdown 代码围栏的脚本解析失败。EJS 模板会报告原始错误，避免被二次报错掩盖；互动页面也不会因空白框架的首次加载提前结束加载提示。
- **补齐部分酒馆世界书与扩展接口。** 完善世界书读取、编辑、条目更新与兼容脚本所需的模块接口；保存变量或附加数据时，不会仅因正文同步时机不同被误判为冲突，过期的正文覆盖仍会被拦截。
- **改进导入预设与模型请求的兼容性。** 支持酒馆的提示词后处理选项，包括合并同角色、半严格、严格和单条消息。改进 Gemini、Claude 等原厂协议的系统消息转换，让放在对话末尾的指令不再被错误移到开头。各端支持的模型协议范围不变。

### 新功能

- **保存多套剧情模型连接。** 可在不同服务商、中转和模型之间快速切换，同时保留各套配置的推理强度、提示词后处理和 System 通道设置。
- **世界书和叙事预设更好管理。** 支持同时启用多本通用世界书，为角色设置主世界书和多本附加世界书；切回角色时恢复其上次使用的叙事预设。
- **调整阅读排版。** 在外观工作台预览并调整正文字号、行高和段落首行缩进，保留卡片自带的 HTML 排版。
