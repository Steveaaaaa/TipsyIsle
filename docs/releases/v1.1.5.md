## 1.1.5：大型角色卡流畅加载、流式显示与删楼/多模型完整体验

> 本版本整合了 1.1.4 的全部新特性，并重点修复了移动端与大型角色卡（如多世界书/多脚本复杂卡）在触控拦截、流式出字、楼层排版与冷启动闪退上的兼容与性能问题。

### 修复与兼容增强

- **大型角色卡流式出字与同层脚本兼容。**
  - 修复部分角色卡通过显示正则把 `<content>` 等叙事标签替换为空占位槽（如 `<div data-...></div>`）时，流式预览将正文吞掉导致“卡住不出字 / 仅出开头后停住”的问题。
  - 修复回复结算后空占位槽、或与裸 HTML 文档及 `<script>` 部件共存的未引用 `data-*` 占位槽被隔离进子 `iframe`，致使外层楼层脚本找不到挂载点、报错并破坏原有排版与边距的问题。
  - 流式输出容器与 `.mes_text` 隔离并加固 `StreamingView` 插入锚点，避免监听 `#chat .mes_text` 的脚本在出字期间清空流式 DOM；为脚本直接接管 `.mes_text` 渲染的正文补上零优先级（`:where()`）默认字体与内边距兜底。
  - 修正原生客户端主动取消流式请求时的 `AbortError` 诊断记录。
- **角色切换与移动端触控不再误锁屏幕。**
  - 切换角色卡时重建 `CompatibilityChat` 兼容宿主实例，防止上一个角色的脚本或全局浮层状态残留到当前对话。
  - 精确区分真正全屏拦截操作的弹窗与导入期 `0×0` 隐藏框架、`pointer-events: none` 悬浮 HUD、全屏背景 `<canvas>`、纯透明全屏容器及低 `z-index` 背景层，仅由原生弹窗控制遮罩拦截状态，解决移动端导入复杂卡后屏幕按钮无法点击的问题。
- **删除楼层能正常保存。** 修复删除单条消息时阅读区变成纯色、重开后消息又出现的问题。删除后会重新编号并保留后续消息；写入存档失败时会回退，角色会话仍会按新楼层编号重初始化兼容运行环境。
- **卡片脚本、模板与世界书接口兼容。** 修复 `window.parent` / `top` 跨域报错、带 Markdown 代码围栏的脚本解析、EJS 原始错误透传以及互动页面在空白框架首次加载时提前结束加载提示的问题；补齐 `/api/worldinfo/*` 等酒馆世界书读取、编辑与条目更新接口，减少变量与附加数据写入冲突误判。
- **改进导入预设与模型请求兼容性。** 支持酒馆提示词后处理模式（合并同角色、半严格、严格、单条消息），并改进 Gemini、Claude 等原厂协议末尾指令转换（各端支持的模型协议范围不变）。

### 性能优化

- **大幅降低大型角色卡内存占用与安卓端冷启动闪退风险。**
  - 归一化存储与水合时自动剥离 `rawData` 中与条目正文、内置世界书和脚本目录重复的大体积副本，并在导出与编辑器回写时保持完整无损还原；启动时会自动压缩瘦身本地已存的旧版大型卡片数据。
  - Rust 原生存储读取接口 `tipsy_kv_get` 改为原始 JSON 字符串零 AST 透传，消除加载时的多层反序列化与再序列化内存峰值。
  - 大型内嵌世界书与故事快照进入去重池，冷启动改为顺序水合与单条逐个拉取大型资产记录；限制长文本哈希缓存体积以防止大串滞留堆内存，并精简兼容上下文里的冗余角色卡大字段拷贝。

### 新功能

- **保存多套剧情模型连接。** 可在不同服务商、中转和模型之间快速切换，各自保留推理强度、提示词后处理与原厂 System 通道配置。
- **世界书与叙事预设更好管理。** 支持同时启用多本通用世界书，为角色绑定主世界书与多本附加世界书，切回角色时自动恢复上次使用的叙事预设。
- **调整阅读排版。** 在外观工作台预览并调整正文字号、行高和段落首行缩进，保留卡片自带的 HTML 排版。
