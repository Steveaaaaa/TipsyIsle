## What's new in TipsyIsle 1.1.2

- **Fixed blank replies in Lamplight Chat.** The app now reads more reply formats from model relays. If the model sends no reply text, the app reports the issue and keeps your message so you can retry. If you already have 1.1.2, download the replacement installer from the release page and install it over your current copy.
- **Export a report straight from an error notification.** Choose **Export error log** to save a `.txt` report with your runtime environment, installed plugins and scripts, and recent errors. You can also view and clear logs under **Settings → Advanced & Diagnostics → Error Log**. The file is yours to share; reports omit API keys, chat text, and full requests.
- **See where an update check went wrong.** The log distinguishes connection timeouts and GitHub errors from an up-to-date app, an ignored release, or a new version with no installer for your device.
- **List models from HTTP endpoints.** The installed apps can now reach HTTP-only model services on custom ports for model discovery, provided the service exposes a model list for the selected protocol.
- **Better compatibility with SillyTavern dialogs.** Cards and presets can use more dialog behaviors, including input, confirmation, and image cropping. Dialogs can also appear while a creator page is starting up.
- **Dialogue is easier to spot.** Plain reading prose highlights lines enclosed in curly quotes, straight double quotes, or `「…」`, while interactive author pages retain their own styling.
