## TipsyIsle 1.1.4: message deletion, model profiles, and compatibility

### Fixes

- **Message deletion is saved reliably.** Fixed a blank reading area after deleting a message and the deleted message reappearing after reopening the conversation. Remaining messages are renumbered, and a failed save rolls back the deletion. Story chats still reinitialize the compatibility runtime so scripts use the new message numbers.
- **Better card script and template handling.** Fixed cross-origin errors for some uses of `window.parent` and `top`, and parsing failures for scripts wrapped in Markdown code fences. EJS shows the original error, and interactive pages no longer dismiss their loading indicator on the initial blank frame load.
- **Broader SillyTavern worldbook and extension support.** Improved worldbook reads, edits, entry updates, and module compatibility. Saving variables or message metadata no longer fails solely because the text snapshot is out of date; stale text overwrites are still rejected.
- **Better prompt preset and provider compatibility.** Added SillyTavern prompt post-processing modes, including role merging, semi-strict, strict, and single-message modes. Improved native Gemini and Claude system message handling so instructions placed at the end of a conversation stay there. Provider availability on each platform is unchanged.

### New

- **Story model connection profiles.** Save and switch between providers, endpoints, and models with their own reasoning, prompt post-processing, and system prompt settings.
- **More flexible worldbook and preset bindings.** Enable multiple global worldbooks, assign a primary and additional worldbooks to a character, and restore that character's last-used narrative preset when switching back.
- **Reading typography controls.** Preview and adjust body text size, line height, and first-line indentation in the Appearance Studio without overriding card-authored HTML styling.
