## 微醺屿 1.2.0

> 本版本自 v1.1.6 以来迎来重要里程碑：**Plugin SDK 1.2** 正式落地，旗舰叙事视觉插件 **「浮光 · Lumina Director」** 登场；同时新增 **OpenAI Responses** 原生支持、**Shadow DOM 流内兼容渲染**、**SPreset 运行时**，并修复 Gemini 流式、Izumi/MVU 兼容与移动端体验。

### 旗舰插件与 Plugin SDK 1.2

- **「浮光 · Lumina Director」（v1.2.16）**：此前预告的「小屿浮光」正式上线，基于 Plugin SDK 1.2.0 构建，提供无感沉浸式叙事视觉导演体验（已打包于 `releases/plugins/lumina-director.tipsy-plugin`）：
  - **零配置自动建档与首帧定妆**：自动读取角色卡、世界书人物词条、Persona 与图库绑定参考图；群像与模拟器卡自动跳过封面并启用首帧定妆自举。
  - **流式抢跑与全文兜底**：通过 `story.replyCheckpoint` 在前两段命中转场或强视觉动作时提前后台显影，平淡开篇则等待 `story.replySaved` 后捕捉高潮，支持日常观察型镜头与多档分镜频率。
  - **多生图协议与布局自适应**：支持 OpenAI 兼容、Gemini 原生多模态、NovelAI V4.5（坐标防串色与参考图）、ComfyUI 自动槽位工作流与 SD WebUI，并随轻小说、Galgame、网聊、气泡布局自动匹配画幅与风格。
  - **原位胶片叠与随滚舞台**：支持 `< 1/2 >` 原位翻页、一键 `↻ 换一镜`、折叠琥珀胶片签、完整主提示词留档、随滚柔焦舞台背景、跨分支场记连续性，以及「本线胶片轨」「暗房精修台」和跨插件 `chronicle` 图文编年史服务。
- **Plugin SDK 1.2.0（`@tipsy-isle/plugin-sdk`）**：新增 `ui.stage` / `ui.surface` / `ui.export`、回复媒体槽位（`ReplyMediaSlot`）、流式检查点事件（`story.replyCheckpoint`）、生图协议适配与任务调度、向量与视觉索引以及 `director.d.ts` 类型定义。

### 模型协议与流式体验

- **新增 OpenAI Responses 原生适配器**：原生支持 OpenAI Responses API，并支持已保存模型配置即时接管生成通道。
- **修复 Gemini 原生流式与思考阶段**：改进 Gemini 原生流式输出、思考（thought）阶段状态处理，以及增量 JSON / NDJSON / SSE 分帧解析。
- **SPreset 与消息指标**：新增 SPreset 运行时与流式输出支持，并在消息底部新增耗时/Token 等消息指标栏。

### 角色卡与酒馆生态兼容

- **流内 Shadow DOM 兼容渲染（Compat Films）**：将兼容交互页面与媒体内容以流内隔离的 Shadow DOM 形态嵌入对话流，兼顾排版自适应、块级协调与样式隔离。
- **Izumi / MVU 与脚本兼容修复**：允许生成准备阶段的非结构化原地编辑并将 `WORLD_INFO_ACTIVATED` 编辑同步到提示词组装；增强 MVU JSONPatch 对非数组与空块的容错；修复全局脚本删除持久化与 HTML 美化兼容。

### 界面、编辑与稳定性

- **消息编辑与移动端优化**：新增独立的消息编辑弹窗与剪贴板辅助；移动端新增内联外观工作台标签页、插件模型返回导航与更扁平化的设置界面。
- **性能与维护**：清理旧版冗余 CSS 与死代码，改进同步去重、应用更新检查及移动端交互稳定性。
