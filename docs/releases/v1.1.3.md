## MVU 变量卡更稳了，正则与脚本也能直接管起来

- **修复 MVU 角色卡对话时变量不更新、前端美化状态栏不渲染的问题。**
  - 修复提示词组装扫描世界书时，因缺少消息变量作用域导致 `{{format_message_variable::stat_data}}` 被求值为 `"null"` 的问题，模型现在每轮都能完整收到当前变量树。
  - 修复第 0 楼在封面与剧情开局间切换时覆盖已初始化 MVU 变量快照的问题，并支持脚本动态改写开场后自动重新初始化变量。
  - 补齐无脚本回退结算路径中的 `<StatusPlaceHolderImpl/>` 状态栏占位与完整作用域，清理「随 AI 输出」模式下 `[mvu_plot]` 中禁止输出 `<UpdateVariable>` 的冲突规则，并让仅通过正则嵌入前端状态栏脚本的卡片也能准确进入兼容运行环境渲染。
- **新增「正则管理」与「酒馆助手脚本管理」面板。** 现在可在「设置 → 故事运行 / 插件」中管理全局、当前预设、当前故事三个作用域的正则与 TavernHelper 脚本：支持开关启停、手动新建、完整编辑、上下排序、删除及 JSON 导入导出；主界面的导入入口也已支持直接导入独立正则 JSON 和酒馆助手脚本 JSON。
- **完善「故事会话」管理与双端同步体验。** 新增故事会话管理器，支持会话搜索、重命名、多选批量删除与快速切换，并在局域网同步时保留会话名称；兼容预设中的原始 SillyTavern 正则格式。
- **包含对「夜灯畅谈」空白回复的修复。** 适配更多中转接口的返回格式，接口无有效正文时会保留输入并给出错误提示（此前已合入本地提交）。
