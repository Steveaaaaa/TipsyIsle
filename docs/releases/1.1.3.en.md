## What's new in TipsyIsle 1.1.3

- **Fixed MVU dialogue variable updates and status panel rendering.**
  - Fixed worldbook scanning during prompt assembly where `{{format_message_variable::stat_data}}` evaluated to `"null"` due to missing message variable scopes, ensuring the model always receives the current variable tree.
  - Fixed switching between cover and story swipes on floor 0 overwriting initialized MVU snapshots, and automatically re-initializes MVU when scripts replace the opening greeting dynamically.
  - Appended `<StatusPlaceHolderImpl/>` with full variable scopes in script-free MVU settlement, removed conflicting extra-model-only `[mvu_plot]` rules during inline mode, and improved compatibility host detection for regex-embedded MVU status panels.
- **Added Regex Manager and TavernHelper Script Manager.** Manage regex rules and TavernHelper scripts across Global, Active Preset, and Active Character scopes under **Settings → Story Running / Plugins** (toggle, create, edit, reorder, delete, and import/export JSON). Standalone regex and TavernHelper script JSON files can also be imported directly from the library import button.
- **Improved Story Conversation management and preset compatibility.** Added story conversation search, renaming, multi-select bulk deletion, and LAN sync title preservation, plus raw SillyTavern regex support in preset writes.
- **Includes the Lamplight Chat blank-reply fix.** Handles additional relay response formats and keeps your prompt with a clear error when a relay returns no text.
