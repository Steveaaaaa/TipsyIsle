## TipsyIsle 1.1.6

- **AVS V4.1.10:** Its independent API panel now fills in the model saved for the selected proxy preset and can fetch that connection’s model list. You can still enter a model manually; reimporting AVS is not required.
- **TavernHelper compatibility:** Improved extension menu detection and cancellation and event handling for background generation.
- **Preset switching:** Saved prompt text and enabled states survive switching presets. Presets no longer override your streaming preference.
- **Worldbooks and story routes:** See active worldbooks and manage their entries directly. Delete individual routes, branches, or saved conversations with a confirmation that identifies what will be removed.

**Coming soon:** The flagship plugin **小屿浮光** is getting an update. It is not included in 1.1.6; details and availability will be announced separately.
