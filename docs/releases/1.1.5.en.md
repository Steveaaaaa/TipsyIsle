## TipsyIsle 1.1.5: large-card stability, streaming & layout fixes, and 1.1.4 features

> This release includes everything planned for 1.1.4 alongside critical compatibility and memory performance fixes for large, script-heavy character cards on Android and desktop.

### Fixes & Compatibility

- **Live streaming and floor-script compatibility for placeholder-slot cards.**
  - Fixed streaming preview hiding story prose behind loading placeholders when a card's display regex replaces narrative tags (such as `<content>`) with empty `data-*` slot divs.
  - Fixed settled empty `data-*` slots—including slots following unfenced `<html>` documents or coexisting with unreferenced inline `<script>` widgets—being trapped inside child `<iframe>` elements instead of staying in `.mes_text` for floor scripts to populate.
  - Isolated live streaming containers from `.mes_text` with a resilient `StreamingView` anchor so `#chat .mes_text` observers do not wipe active stream DOM; added zero-specificity (`:where()`) fallback reading typography and padding for script-rendered prose; improved native abort diagnostics (`AbortError`).
- **Clean character switching and mobile touch-lockout fix.**
  - Remounts `CompatibilityChat` when switching characters so previous character script or overlay state does not leak across sessions.
  - Ignores hidden `0×0` iframes, `pointer-events: none` HUD containers, ambient `<canvas>` layers, transparent wrappers, and low `z-index` backgrounds when checking for blocking extension overlays, and scopes `data-compat-popup` to native popups.
- **Reliable message deletion.** Fixed the blank reading area and deleted messages reappearing after reopening a conversation, with safe tree renumbering and save rollback.
- **Broader SillyTavern worldbook, script, and preset support.** Fixed cross-origin `window.parent` / `top` handling, fenced script parsing, EJS original error reporting, `/api/worldinfo/*` compatibility, prompt post-processing modes, and Gemini/Claude trailing system prompt placement.

### Performance

- **Major memory reduction and Android OOM crash fix on large character cards.**
  - Eliminated multi-copy `rawData` bloat across normalized character cards and lorebooks (while preserving lossless round-trip serialization) and auto-compacts previously stored bloated assets on startup.
  - Changed native SQLite reads (`tipsy_kv_get`) to stream raw JSON payloads directly without intermediate `serde_json::Value` AST allocation.
  - Pooled large embedded lorebooks and story state records, switched startup hydration to sequential / single-asset loading, bounded hash caches to small strings, and slimmed oversized fields in compatibility `rawCharacter` snapshots.

### New

- **Story model connection profiles.** Switch between providers and endpoints while keeping per-profile reasoning effort, prompt post-processing, and system prompt settings.
- **Flexible worldbook and preset bindings.** Enable multiple global worldbooks, bind primary and additional worldbooks per character, and restore each character's last-used narrative preset.
- **Reading typography controls.** Preview and adjust font size, line height, and first-line indentation in the Appearance Studio.
