# 微醺浮光 · Lumina Director 1.2

无感沉浸式叙事视觉导演插件，基于 TipsyIsle Plugin SDK `1.2.0` 构建。

## 核心能力
- **完整主提示词留档**：新生成的每一帧都会保存实际提交的完整主提示词，可在「暗房精修台」的镜头描述里查看；旧帧已截断的内容无法补回。
- **零配置自动建档**：自动读取角色卡、世界书人物词条、玩家 Persona、远程内置图鉴与本地图库（`StoryGallery`），按角色别名与场景服装自动绑定参考图；群像/模拟器卡自动跳过封面并启用**首帧定妆自举**。
- **高置信度流式抢跑 + 全文兜底**：`story.replyCheckpoint` 在前两段命中明确转场或强视觉动作时提前后台显影，平淡开篇则等待全文保存（`story.replySaved`）后捕捉高潮段，也可在设置中开启「仅在回复保存后显影」。
- **四大生图协议与布局自适应**：支持 OpenAI 兼容 / Gemini 原生多模态 / NovelAI V4.5（坐标防串色与参考图）/ ComfyUI 自动槽位工作流 / SD WebUI，并根据当前阅读布局（轻小说、Galgame、网聊、气泡）自动匹配画幅与风格。
- **原位无损胶片叠（Take Stack）与随滚舞台**：支持 `< 1/2 >` 原位翻页、一键 `↻ 换一镜`、折叠为页边琥珀胶片签、保存原图，以及跨楼层延续的柔焦舞台背景（礼让自定义壁纸）。
- **分支场记连续性 & 跨插件服务**：随故事分支自动分叉回滚服装、天气与伤势状态；提供 `dev.tipsy-isle.lumina-director.visual` 服务供「剧情手记」直接生成图文编年史。
