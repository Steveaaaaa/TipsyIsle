# 蜜桃蔷薇 · Pêche & Rose

一套以植物版画和烫金信笺为灵感的 TipsyIsle 外观。蜜桃粉、珍珠白、玫瑰金和一点灰绿，在夜间换成深莓色和暖铜色。

在 TipsyIsle 里打开「外观 → 外观包 → 导入外观包」，选择 `蜜桃蔷薇.tipsy-appearance.json`，点「保存外观」。包里已经包含全部图片和样式，导入后可离线使用。

桌面和手机共用外观包，分别使用横版和竖版花卉底图，并调整花纹、文字和控件尺寸。外观主要装饰应用界面：角色卡自带的状态栏、互动页面和正文保持原有显示方式。

修改素材或 `skin.css` 后，运行 `node examples/appearance/peach-rose/build.mjs` 重新打包。

`folio.webp`、`mobile-folio.webp` 和 `seal.webp` 由授权的图像 API 使用 `gpt-image-2.6-sunburst` 生成，提示词见 [`art-direction`](./art-direction/)。线条纹样和图标为本包单独绘制。
